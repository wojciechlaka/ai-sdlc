# Seed-Tickets für das Beispiel-Repo „coffee-chat"

Diese Tickets sind bewusst roh und unterspezifiziert formuliert — so, wie sie ein Stakeholder
ins Backlog werfen würde. Sie sind der Input für den Refinement Agent, der sie gegen das Repo
[qvest-digital/coffee-chat](https://github.com/qvest-digital/coffee-chat) schärft.
Eine Datei pro Ticket; das Format ist zugleich die Vorlage für den Markdown-Import (T-17).

Kontext zum Repo: Realtime-Multiplayer-Partyspiel für Remote-Teams. Next.js 15 (App Router)
mit Custom Node-Server, WebSockets (`ws`), TypeScript-Monorepo mit `packages/shared`,
kein Persistenz-Layer — der gesamte Spielzustand lebt in-memory.
